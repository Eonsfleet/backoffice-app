## Required modules not complete

Onboarding checklists; complete driver compliance/detail and assignment history; platform clusters/geofences; installation jobs and evidence; vendor operations; incidents/support; requisitions; generated-report operations; integrations/webhooks/API clients; telemetry/realtime/delivery/job history; feature flags and reference-data administration remain incomplete. Customer health is partial. Installer directory is partial because the verified response does not load relationships.

Do not replace those workflows with generic empty pages or speculative endpoints. Backend source exists in `../api`, contrary to the earlier audit. Its presence does not establish a working global admin contract for every customer route: geofences use a policy typed to `App\Models\User`, clusters/incidents use Spatie client-permission middleware, reports explicitly use `auth:client`, and vendor services resolve organization context. Those need a verified admin scope and authorization model, with tenant boundaries and audit records, before frontend integration. API keys and webhook secrets must remain redacted.

## Validation record

Current automated and browser results are recorded in `rebuild-audit.md` and `qa/browser-results.json`. Browser interception validates rendering and interactions against contract-shaped fixtures; it does not validate a live account, actual backend role grants, database state or delivery behavior. No deployment has been performed.

Legacy /subscriptions/transactions, /subscriptions/invoices and /subscriptions/reconciliation routes now redirect to their canonical /billing pages, preserving query parameters. See [commercial workspace separation](commercial-workspace-separation.md).
